# Android Vitality

Open source system diagnostics and resource monitoring tool for Android. Provides hardware, software, and real-time performance metrics with no data tracking.

## Features

- System Diagnostics: Data on SoC, Motherboard, Bootloader, and Radio firmware.
- RAM Monitor: Breaks down Marketed vs Usable RAM and hardware-reserved memory.
- Battery: Health, temperature, voltage, and technology profiling.
- Display Metrics: Resolution, refresh rate (Hz), and physical size.
- Sensor Inventory: List of hardware sensors with vendor and power data.
- Vendor OS Detection: Detection for One UI, MIUI, OxygenOS, ColorOS, EMUI, and FuntouchOS.
- Report Export: Generate text-based system reports.
- Material 3 UI: Clean layout with dark mode support.

## Privacy

- Zero Data Collection: No diagnostic data is collected or transmitted.
- 100% Local: All processing happens on the device.
- No Analytics: No tracking pixels or remote logging.

## Tech Stack

- Kotlin
- Jetpack Compose (Material 3)
- MVVM + StateFlow
- Kotlin Coroutines

## Installation

Download the latest APK from the [Releases](https://github.com/protocol4/AndroidVitality/releases) page and install it on your device.
